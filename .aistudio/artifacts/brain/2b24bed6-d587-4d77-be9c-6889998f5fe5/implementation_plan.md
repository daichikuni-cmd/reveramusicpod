# ライブラリスクリーンのQueue（再生待ち行列）ボトムシート実装計画

ライブラリスクリーン（MusicHubScreen）のカテゴリタグ（アルバム/アーティスト/全曲/最近）の上部に、現在再生中の楽曲および次に控える楽曲を確認できる「Queueバー」を新設し、タップ時に下からスライドして全曲リストを展開・スキップできる「Queueボトムシート（ModalBottomSheet）」を導入します。

---

## ユーザー確認済み仕様・決定事項

> [!IMPORTANT]
> ユーザー様からの回答に基づき、以下の確定仕様に従って実装します。

- **表示スタイル**: タップで下から開くボトムシート形式（`ModalBottomSheet` または専用アニメーションボトムシート）。画面上部のQueueバーには「現在再生中の曲」と「次の曲名プレビュー」をコンパクトに表示。
- **ウィンドウのクローズ**: ボトムシート上部に明示的な「閉じる（✕）」ボタンとドラッグハンドルを配置し、外側タップや下スワイプと合わせて確実に閉じられるように設計。
- **キュー操作性**: タップした楽曲への即時スキップ再生のみ（誤操作を防ぐシンプルなDAP向けUX）。
- **再生順序**: 現在決定しているプレイリストの順序に従い、現在曲から後ろの曲を順番に表示。

## 1. 概要とユーザー体験

### 主な機能
1. **Queueプレビューバー（タグ一覧の上に配置）**
   - カテゴリチップ（アルバム、アーティスト、全曲、最近）の直上に配置。
   - 左側に「QueueMusic」アイコンと「再生中: [曲名]」、右側に「次の曲: [曲名] >」をスリムに表示。
   - 音楽が停止中・未選択時は「再生中のキューはありません」と控えめに表示。
   - タップすると心地よいハプティックフィードバックとともにQueueボトムシートが下からスライド表示。
2. **Queueボトムシート（下から展開）**
   - **ヘッダー**: 「再生キュー（残り X曲）」のタイトルと右上に「✕ 閉じる」ボタン、上部にドラッグハンドル。
   - **NOW PLAYING（現在再生中）エリア**:
     - アクセントカラー（`AntiqueGold` / `AccentGreen`）で強調された専用カード。イコライザーアニメーションアイコン、曲名、アーティスト、再生時間。
   - **UP NEXT（次に再生）エリア**:
     - 番号付きリスト（1, 2, 3...）で次に流れる楽曲を曲単位で一覧表示。
     - 各アイテムをタップすると即座にその曲へスキップして再生開始。
     - 画面下部のシステムナビゲーションバー（gesture bar / 3-button）との被りを防止する `WindowInsets.navigationBars` セーフエリア対応。

## 3. 技術設計・アーキテクチャ

### 1) 状態管理（Data Model & ViewModel）
- `PlaybackUiState` に現在再生中のプレイリスト情報（`currentPlaylist: List<TrackInfo>` と `currentIndex: Int`）を保持。
- `MusicPlayerManager`:
  - 楽曲再生（`playTrack(track, playlist)`）時に、`currentPlaylist` と `currentIndex` を `PlaybackUiState` に確実に反映。
  - `skipToQueueIndex(index: Int)` メソッドを追加（キュー内タップで直接指定トラックを再生）。
- `MusicLauncherViewModel`:
  - `playbackState.collectAsStateWithLifecycle()` を通じて、ライブラリスクリーンおよびボトムシートへ常時リアクティブに最新キューを供給。

### 2) UIコンポーネント設計
- **`QueuePreviewBar` (`MusicHubScreen.kt` 内)**:
  - 高さ約48dpの角丸サーフェス（ダークグレー背景＋微細なゴールド/グリーン枠線）。
  - 曲の再生状態（再生中/一時停止）と連動したステータス表示。
  - タップで `isQueueSheetVisible = true` に設定。
- **`QueueBottomSheet` (`MusicHubScreen.kt` または `QueueBottomSheet.kt`)**:
  - Material 3 の `ModalBottomSheet` または Compose `AnimatedVisibility` を活用したボトムスライドシート。
  - `sheetState = rememberModalBottomSheetState(skipPartiallyExpanded = true)`。
  - 閉じるアクション:
    - 右上の「✕」ボタンクリック
    - スクリム（暗い背景）クリック
    - 下方向ドラッグ
    - Android 戻るボタン（BackHandler）

## 4. 検証計画

1. **表示確認**:
   - アルバム/フォルダから連続再生を開始した際、タグ一覧の上にQueueバーが正しく表示されること。
   - タップ時にボトムシートがスムーズに下から表示されること。
2. **閉じる機能確認**:
   - 右上の「✕」ボタン、背景タップ、下スワイプ、端末戻るキーのそれぞれで確実に閉じること。
3. **即時スキップ確認**:
   - キュー内の「次の曲」をタップした際、即座にその曲に切り替わり、Now Playing表示が更新されること。
4. **セーフエリア・ビルド確認**:
   - 画面最下部のシステムナビゲーションバーとキュー内の最下部曲が重ならないこと。
   - `compile_applet` および既存単体テスト（`gradle :app:testDebugUnitTest`）がパスすること。
